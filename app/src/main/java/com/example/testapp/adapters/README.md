# 🔗 adapters

> RecyclerView adapters for displaying lists throughout the app.

| Adapter | Displays | Key Fields |
|:--------|:---------|:-----------|
| `FoodsAdapter` | List of `Food` items | name, price, image |
| `CartAdapter` | List of `Cart` items | title, total price, item count |
| `UserAdapter` | List of `User` items | name, email |
| `ImageSourceAdapter` | Image source options | camera / gallery selection dialog |
